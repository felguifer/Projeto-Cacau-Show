# Cacau Show — Projeto Universitário

Protótipo front-end criado para demonstrar soluções para os 5 problemas levantados:

1. Dificuldade na localização de produtos → busca, filtros e ordenação.
2. Erros humanos na inserção → formulário com validações.
3. Falta de catálogo/aba dedicada → aba Catálogo com produtos organizados.
4. Falta de autoatendimento → FAQ interativo.
5. Falta de identificação automática de cupons → validação automática de códigos.

## Como executar
Abra o arquivo `index.html` no navegador.

## Divisão sugerida do grupo
- Felipe: integração geral, área de cadastro/validações e apresentação do projeto.
- Menina 1: Catálogo — organização dos produtos, filtros, pesquisa e layout dos cards.
- Menina 2: Autoatendimento + Cupons — perguntas frequentes, fluxo de ajuda e validação dos códigos.
